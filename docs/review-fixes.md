# 2026-10-03 检查问题修复

本次修复针对 `c1747ea` 的检查报告；不新增账号、同步、AI 或统计图表功能。

| 原问题 | 修复 |
| --- | --- |
| 手动分摊允许非法、负数、超额输入 | 表单逐项解析；空白明确为 0。仓库在事务内二次校验金额、总额、所属订单，失败全部回滚 |
| 混币种商品直接用最小单位做比例 | 混币种商品禁用 BY_PRICE；添加/移入/修改商品也不能绕过限制，费用币种可以与同币种商品不同 |
| 旧请求覆盖当前 VN/Release | 搜索与 Release 使用 Job 取消、请求代次及 VN ID 校验；选择与保存再次验证关联 |
| 新克隆缺少 SDK 配置 | 脚本自动生成 `local.properties`，不覆盖已有配置；wrapper 自动发现项目内 SDK，缓存/下载位于 `toolchain/` |
| 订单列表/详情合计不同 | 明确区分实际支出、已分摊收藏成本、未分摊费用；统一实际支出为商品价 + 全部费用 |
| 费用预览算法与保存不同 | 预览直接调用完整订单引擎；新增/编辑均采用相同费用池计算 |
| VN 搜索和 Release 缺少分页 | 搜索可加载下一页并重试；当前 VN 的 Release 分页取全、去重，只在所有页成功后替换缓存 |
| 合辑缓存 VN 关联覆盖 | Room v2 新增 `release_vn` 多对多关联，迁移保留已知缓存关联及所有购买事实 |
| 写入失败无提示或崩溃 | 可见错误提示，保留未保存表单，可修正后重试；取消异常不被吞掉 |

另外处理了金额汇总溢出、极大科学计数金额输入、自动系统备份的隐私承诺，以及 MPL 说明中“分发时”的限定。
不为了消除升级提示自动更新 Kotlin/AGP/SDK 依赖版本。
